お客様の来店情報を フォームで入力 すると、地図 に「来店のきっかけ」別で色分け表示され、 どのチラシ・きっかけがどのエリアの来店につながっているかが一目で分かります。

毎日の使い方 スタッフ向け

この4ステップだけ覚えればOKです。

① お客様の情報を入力
上の「📝 入力フォーム」を開き、次を入力して送信します。
郵便番号（分からなければ住所）／丁目／性別／年代／来店のきっかけ
※郵便番号か住所のどちらか一方でOK。個人名は入力しません。
② 地図で見る
「🗺️ 来店客マップ」を開きます。
・ 赤い家アイコン＝お店（守山大森店）
・色のついた丸＝来店客（来店のきっかけ別に色分け）
③ 最新にする（🔄 更新ボタン）
入力した内容を地図に反映したいときは、左上の 「🔄 更新」 を押します。
1〜2分で新しいピンが表示されます（設定により最大10分の場合あり）。
④ 分析する（📊 分析・CSV）
左上の 「📊 分析・CSV」 を押すと、来店のきっかけ・年代・性別・エリア・日別のグラフが見られます。
「⬇ CSVダウンロード」でExcel用データも保存できます。

便利な操作

  • 絞り込み（右上）：来店のきっかけ・性別・年代のチェックを外すと、その条件だけ表示できます。
  • まとめ表示：地図を引く（ズームアウト）と、同じ丁目のお客様が 件数の数字 でまとまります。数字をクリック（または拡大）すると1件ずつに分かれます。
  • 間違えたデータを消す：ピンをクリック →「🗑 このデータを削除」。（初回のみ下の「初期設定」が必要です）

初期設定（削除・今すぐ反映） 管理者向け・1回だけ

「削除」や「今すぐ反映」を使うときだけ必要です。ふだんの入力・閲覧・分析には不要です。

❓「Apps Script WebアプリのURLを貼り付けてください」と出たら？
それは Googleスプレッドシートの拡張機能（Apps Script）で作ったウェブアプリのURL のことです。 https://script.google.com/macros/s/……/exec で終わるURLで、下の②で取得します。

① Apps Script を用意する

  1. 回答用スプレッドシート「買取大吉 来店客記録（名古屋）」を開く
  2. メニュー 拡張機能 → Apps Script を開く
  3. 管理者から渡されたコード（delete_customer.gs）を貼り付け、TOKEN に合言葉を設定して保存

② ウェブアプリのURL（.../exec）を取得する

  1. Apps Script 右上の デプロイ → 新しいデプロイ → ウェブアプリ （実行するユーザー＝自分／アクセスできるユーザー＝全員）
  2. 表示された .../exec のURLをコピー（これが上の質問で貼り付けるURL）
  3. すでに作成済みなら デプロイ → デプロイを管理 → ウェブアプリ からURLをコピーできます

③ 地図に登録する（端末ごとに1回）

  1. 地図の左上 「⚙ 削除の設定」 をクリック
  2. コピーした .../exec のURLを貼り付け
  3. 合言葉（TOKEN）を入力 → 「保存しました」と出れば完了
⚠️ コードを更新したら「新バージョン」でデプロイ
Apps Scriptは「保存」だけでは反映されません。必ず デプロイを管理 → 編集(鉛筆) → バージョン＝「新バージョン」→ デプロイ をしてください（URLは変わりません）。 削除が急に動かなくなった時は、たいていこれが原因です。

④「今すぐ反映」を使う場合（任意）

更新ボタンで即座（1〜2分）に反映させたい場合のみ。設定しなくても自動更新はされます。

  • GitHubの「fine-grained トークン」（対象リポジトリ＝nagoya-customer-map／権限＝Actions: Read and write）を作成
  • Apps Script の プロジェクトの設定 → スクリプト プロパティ に GITHUB_TOKEN として登録

困ったときは（FAQ）

Q. 更新ボタンを押しても新しいお客様が出てこない
表示されるメッセージを確認してください。「未設定です」→ ⚙削除の設定を登録。「反映エラー…」→ そのメッセージ内容を管理者へ。何も設定していない場合は、最大10分ほどで自動反映されます。
Q. 削除できない／「削除できませんでした」と出る
Apps Scriptを「新バージョン」でデプロイし直してください（上の⚠️参照）。
Q. 郵便番号が分からないお客様
フォームの「住所」欄に住所を入力すればOK。地図にちゃんと反映されます。
Q. 中日新聞など、来ていないきっかけが0件で残っている
0件のものは自動で消えます。表示が古い場合は「🔄 更新」または画面を再読み込みしてください。
Q. 個人情報は大丈夫？
個人名は集めません。地図の位置は約100mずらして表示し、詳細な番地は保存・表示しません（市区町村まで）。
